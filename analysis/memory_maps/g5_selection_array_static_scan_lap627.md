## 확인한 사실

- `0x00899024` int32 = 선택 수(기존 `original_qhd_probe_0910.md`). 직접 참조 9곳:
  `0x412e68/0x412e6e`(추가 +1), `0x412ecc/0x412ed2`(제거 -1), `0x41d360`, `0x41f599`(`cmp …,1`),
  `0x498fba`, `0x499872`, `0x49acd1`.
- `0x00899028` = 선택 엔트리 배열, **엔트리 4B(int16 slot + int16 보조값)**, 끝 sentinel `0x00899078`.
  `0x899078-0x899028 = 0x50 = 80B = 20칸`. 기저 참조 29곳(`0x89902a` 1곳 포함), 끝 비교 14곳:
  `0x412dd5 0x412e52 0x412eb3 0x4170bd 0x41dd69 0x41dfaf 0x41f068 0x445e0b 0x499012 0x49904f 0x499577 0x4998c9 0x49aced 0x4a4258`.
- 추가 루틴 `0x412e3c..0x412e6e`: 빈 칸(slot=0,aux=0) 탐색 후 `[ecx*4+0x899028]`에 기록, 끝이면 추가 안 함 → **20 상한은
  별도 상수가 아니라 배열 끝 주소로 강제**된다. 제거 루틴 `0x412e9f..0x412efc`: 일치 칸 0화, count 0이면 `0x898faa`,
  `0x892ffc`, `0x892ffe`, `0x8930a0..0x8930a4` 초기화.
- **제자리 확장 불가 근거:** 50칸(200B)이면 `0x8990F0`까지 필요하지만 `0x8990c8`은 slot 인덱스 word 배열
  (`[reg*2+0x8990c8]`, 34곳 참조; 선택 여부/표식 성격 추정, 미증명)의 기저다. `0x899078..0x8990c7`(80B)의 정체는 미확인.
  → 50칸은 **새 저장소로 재배치**가 전제다.
- **`div 20` 회전 인덱스 3곳:** `0x41ec6a`, `0x41ed57`, `0x41eea8` — `(tick 0x8924c8 + i) mod 0x14`로 선택 칸을 고르며
  `0x41ed15 cmp edi,0x14`가 반복 상한이다(동일 함수 내 다른 두 루프도 같은 구조 추정).
- **부대지정(추정 Ctrl+숫자) 10×20:** `0x445d52..0x445e15`에서 구조체 `[ebp+0x16]`부터 그룹 10개×20칸×4B
  (`0x16+10*0x50=0x336`), 그룹 count word 10개 `[ebp+0x336]`. 선택 배열을 끝까지 순회하며 대상 그룹 포인터
  `[esp+0x10]`를 **선택 칸마다 +4** 한다 → 선택이 20을 넘으면 그대로는 다음 그룹/count로 넘친다. `ebp` 구조체의
  정체(PlayerStruct 여부)와 저장 포함 여부는 미확인.
- **명령 패킷 추정 `0x4ae550`:** 스택 지역 20칸(4B)을 0화 후 선택을 복사하고, `0x4ae5f4 mov ebp,0x14` 루프에서
  `slot | (aux<<12)` 16-bit로 20 word 배열에 압축한다. 명령/네트워크 전송 형식이 20칸 전제일 가능성이 높다(미증명).
- UI 소비자 후보: `0x498fba..0x49904f`, `0x499577`, `0x4998b5..0x4998d2`, `0x49a7df..0x49acf0`(`FUN_0049acc0`),
  `0x4a4242..0x4a4261`. 기타 기저 참조 `0x41708a 0x41dd48 0x41df50 0x41e7fe 0x41e810 0x41eeaf 0x41f03a 0x4ae58c`.

## 미확인(W1 몫)

`0x899078..0x8990c7` 정체, `0x8990c8` 의미·크기, 부대지정 구조체와 저장 포함 여부, 명령 패킷의 단일/멀티 공통 경로와
수신측 상한, UI 초상화 격자 크기, 스택 지역 20칸 버퍼 전수, 레지스터 간접(기저를 레지스터에 싣고 오프셋 접근) 참조 전수,
재배치용 여유 BSS 또는 새 섹션 후보.
