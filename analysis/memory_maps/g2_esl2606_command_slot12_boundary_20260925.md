# G2 ESL 2606: 명령 슬롯 12비트 경계 (2026-09-25)

읽기 전용 원본 PE32 SHA256 `b56986e018b43293be8d9945521d145bba8dbe4e49fe70c6b6488b8c9c08a8ac`; 정확한 ESL 2606 입력 SHA는 일반 `4a03895d8e6690080714fab7e851c3a0e9d44b7cac47fed78fc21a2f5210c6f8`, 시작자리고정 `daf0b6a07f01d04397018924f9dd0c6ff414148c0547adc2d5c9e0b403a58523`이다. 아래 file offset은 이 PE에서 `VA−0x00400000`이다. 다른 버전에 이 주소를 추측 적용하지 않는다.

## 원본 코드의 형식

`0x004AE5F9`는 유닛 전체 ID를 `0x00416F70`에 넘겨 유효성을 확인하고, `0x004AE613: C1 E2 0C` (`shl edx,12`), `0x004AE616: 0B D0` (`or edx,eax`), `0x004AE619: 66 89 17` (`mov WORD [edi],dx`)로 명령 목록의 각 유닛을 WORD 하나에 압축한다. `edx`는 전체 ID의 상위 WORD, `eax`는 슬롯을 포함한다. 역방향에서 `0x004AE9D2: 81 E6 FF 0F 00 00` (`and esi,0x0FFF`), `0x004AEA35: 25 FF 0F 00 00`, `0x004AEB53: 81 E1 FF 0F 00 00`, `0x004AEBC8: 81 E2 FF 0F 00 00`가 하위 **12비트**만 슬롯으로 복원하고 `0x004AE9D8/0x004AEB43/0x004AEBBF: shr ax,12`가 상위 identity 성분을 복원한다. `0x00416FA3–0x00416FBC`는 UnitStruct `+0x29C`의 두 WORD를 비교하므로 그 상위 성분을 버리거나 4→2비트로 축소하면 오래된 identity가 재사용 슬롯에 일치할 위험이 있다. 최대 표현 가능한 슬롯은 `0x0FFF=4095`; 슬롯 4096은 수신 시 슬롯 0으로 잘린다. 이 명령 형식의 위 바이트는 배포했던 N=10001 후보에서도 원본 ESL과 동일하다.

이는 인게임 명령 경로의 직접 근거이며 단순 `owner_count_cap=1200`이나 전비 장부 폭과 별개의 제한이다. 별도 정적 조사에서 `0x004A33ED/0x004A4916`의 12비트는 지도 셀 bitfield로 분류됐다. 이를 유닛 슬롯 인코딩으로 오인해 전역적으로 넓히면 안 된다. 명령 큐 `0x004A3C10`은 `0x004A3C27`의 15 DWORD 복사·`0x004A3C44`의 `ret 0x3C`·dequeue `0x004A3C71/0x004A3C85`의 `0x3C` stride로 **60바이트 고정**이다. 안전한 10,000 지원을 주장하려면 full identity 전달 방법과 명령 기록·복원·큐·저장/로드·멀티 송수신의 호환성을 확인해야 한다.
