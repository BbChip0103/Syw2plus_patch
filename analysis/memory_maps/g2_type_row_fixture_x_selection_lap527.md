- type 2의 `+0x4C` bit 0x10=0이므로 `+0x1BC`=1이다(N181). bit 0x4가 있어 fixture의 모든 유닛(1군)을 때릴 수 있고, 같은 type 2끼리도 서로 때릴 수 있다.
- type 2와 3의 행 차이는 인자 0·2·3·5·12·13·17·44~48뿐이다(스프라이트/표시 계열로 추정). 비교에 쓰는 필드는 같다.
- 런타임 비트 변경은 타입 33·39의 bit 0x4뿐이다(N181 `FUN_0048C630`). type 2는 해당하지 않는다.

## N185 — 정적 값이 곧 런타임 값이라는 것은 가정이다 (preflight로 닫는다)

- 이번 추출은 초기화 코드의 상수다. 시나리오나 국가 데이터가 실행 중 행을 덮어쓰는지는 이 문서가 입증하지 않는다.
  type 5·7·46·110은 런타임 값과 일치했다. 그래서 type 2도 같을 가능성이 높지만, 실행 증거는 아니다.
- ⇒ W36은 시딩 **전에** 실행 중인 게임에서 type 2 행을 읽기 전용으로 다시 읽는다. 비용 13, 1×1, `+0x24`&14==0, `+0x4C`==`0x410005`가 아니면 `ARM_FAIL`이다(가드 완화·다른 타입 대체 금지).
