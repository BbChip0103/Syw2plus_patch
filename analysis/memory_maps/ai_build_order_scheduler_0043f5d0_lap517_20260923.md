## 2. 재무장 스케줄러 (N164, 원본 바이트)

- **호출 케이던스(A7):** `0x43F5D0`의 유일한 호출자 `0x41CBE5`. 직전 `0x41CBC6`~`0x41CBDE`가
  `ecx = 0x956770 + (tick & 7) × 0x3ABC`를 만든다 ⇒ **게임 루프 1회에 owner 1명, owner당 8 tick에 1회**.
- **선택(A6):** `0x43F78F`~`0x43F7BA` LCG(`[0x8924C4]`, `mod 0xFFFB`) 뒤 `edx = rand % 20`(tick<20이면 0).
  `0x43F7C8 cmp word [esi+0xD32],0; jne 0x43FB62` ⇒ 오더가 있으면 **선택 생략·현 오더 실행**,
  없으면 `jmp [rand*4+0x43FD10]`(20칸 선택표). 건설은 **index 2 한 칸뿐**(`0x43F871`).
- **건설 오더 조건(A6):** `0x43F871`: `|tick − [+0x33AC]| > 100`이면 `[+0x33AC]=tick`, `+0xD32=1`, `+0xD34=1`,
  아니면 오더 없이 실행부로(무동작). ⇒ owner가 한가할 때 호출당 **1/20**, 직전 건설 오더 시작 후 100 tick 쿨다운.
- **실행(A4/A5):** 같은 호출에서 `0x43FB62`가 `+0xD32`로 27칸 표 `0x43FD60`을 분기, 1이면 `FUN_0043E0E0`.
  상태1은 **설정된 그 호출 안에서** 곧바로 처리되어 2 또는 4로 넘어간다 ⇒ 호출 사이에 상태1이 남지 않는다
  (lap516 "상태1 0회 포착"의 기계적 설명).
- **발부 계수기:** `+0x3A70`은 초기화(`0x43ECD5`, −10000) 외에 상태3 성공(`0x43E56C`)·상태4 성공(`0x43E78E`)에서만
  tick으로 쓰이고 둘 다 `0x43E7BA call 0x4AF650`(건설 명령 발부) → `FUN_0043F5A0`으로 간다.
  `+0x33AC` 쓰기는 초기화 `0x43ECC3`와 `0x43F88E` 2곳뿐. `+0xD32` 쓰기는 초기화·리셋·스케줄러뿐.
- **산술 천장(N167):** 24,000 tick ⇒ owner당 3,000 호출. 늘 한가하다고 가정하면 건설 오더 시작 간격 기대값은
  쿨다운 ≈13호출 + 기하분포 평균 20호출 ≈ 33호출(≈264 tick) ⇒ **≈91회/24k**(쿨다운 무시 상한 150).
  관측 순증가 9~18채는 이 천장의 **약 10~20%** ⇒ "1/20 케이던스"만으로는 설명되지 않는다. 손실은 다른 오더 점유(`+0xD32≠0`) 또는
  부지/일꾼 실패 또는 완공 전 소실 쪽이다 — 어느 쪽인지는 **`+0xD32`·`+0x33AC`·`+0x3A70` 미기록이라 미판별**.

## 3. M-2 원시 재집계 (B1~B6, 비참조)

표본 1,439, tick 17→24,013, 간격 최대 18·평균 16.69(카드 ≤20 충족). 상태 비율은 표본 수 기준·tick 가중 모두
lap516 §2.1과 owner별 |Δ|≤0.3pp(최대 |Δ| 0.06pp). 상태1·4 표본 0(8/8). 건물 수 시작→끝 전원 일치, 감소 0.
마스크 평균 전원 일치, 마스크 0 표본 비율 0.14~1.53%. max used 8/8 일치. `+0xD34` 기타 값 = {101:529, 5:215, 6:297}.

**N165 — "상태0 = 비활성"은 성립하지 않는다.** 스케줄러는 오더 0x15·0xE·0xD·0xC·7·8·0x11·9·0xA·0x14·0x17~0x19를
`+0xD34 = di = 0`으로 시작한다(`0x43F811` 등). 따라서 `+0xD34 == 0` 85.6~87.9%는 "오더 없음"과 "다른 오더의
하위 상태 0"의 합이며, `+0xD34 == 2/3`도 `+0xD32`가 없으면 건설 오더 소속이 확정되지 않는다(다른 핸들러의
하위 상태일 수 있음, 미검증). 스케줄러가 `+0xD34`에 직접 쓰는 즉치값은 {6, 9, 15, 60, 80, 100, 102}이며 관측된
5·101은 핸들러 진행값으로 추정한다(미검증).

**프록시(판정 아님):** 상태2 진입 36~49회/owner. 이것이 모두 건설 오더라면 부지 탐색 도달 대비 순증가 약 18~38%.
