## N181 — `+0x1D8`은 유닛 생성 시 타입 행 `+0x4C`를 복사한 값이다

| VA | 명령 | 의미 |
|---|---|---|
| `0x411D29` | `mov ecx,[eax+0x9B5274]` | 타입 행(base `0x9B5228`, stride `0x394`) `+0x4C` |
| `0x411D2F` | `mov [ebp+0x1D8],ecx` | 유닛 `+0x1D8` ← 행 `+0x4C` (`FUN_00411A00` 유닛 초기화) |
| `0x411E3B`~`0x411E56` | `mov ecx,[ebp+0x1D8]` … `mov byte [ebp+0x1BC],dl` | `+0x1BC` = (`+0x1D8` bit `0x10` ? 2 : 1) |

`.text` 전체에서 `[reg+0x1D8]`에 쓰는 DWORD 명령은 5개뿐이다. BYTE/WORD 쓰기는 없다(`[esp+0x1d8]` 스택 지역변수 2건 제외).
절대주소 `0x66B968`(stock 풀 `+0x1D8`)에 쓰는 명령도 없다(읽기 `test`만 있음).
- `0x411D2F`: 위 타입 행 복사.
- `0x48CF3C`·`0x48CF58`·`0x48CF91`(`FUN_0048C630`): **타입 byte `0x21`(33)과 `0x27`(39)만** bit `0x4`를 켜거나 끈다.
  조건은 nation 테이블 값(`0x9598E8`/`0x95993C` + nation×`0x3ABC`)==1이다.
- `0x4C4922`(`FUN_004C46A0`): 상수 `0x1AF4`를 쓴다. 특수 초기화이며 이번 판정과 무관하다.

⇒ 타입 5·7·46·110에서 `+0x1D8`은 **실행 중 바뀌지 않는 타입 고정값**이다. 전투 경과나 시야 때문에 켜지는 "표적 가능" 상태가 아니다.
lap524 기록의 "시딩이 플래그를 세팅하지 않는다"·"S1 soak의 자연 발생 빈도로 답이 나올 수 있다"는 추정은 **틀렸다**.

## N182 — 허용목록 {5,7,46}의 시딩 유닛은 구조적으로 아무것도 공격하지 못한다

`FUN_00415880`(P6): 소스 bit `0x4`=0이면 목표 `+0x1BC`==1을 거부한다. 소스 bit `0x400`=0이면 목표 `+0x1BC`==2를 거부한다.

| 타입 | `+0x1D8`(근거) | bit 0x4 (1군 공격) | bit 0x400 (2군 공격) | bit 0x10 → `+0x1BC` |
|---|---|---|---|---|
| 5 (HP1400, 시딩 주력 138기/owner) | `0x4028401` (lap524 실측 7기 + init matrix HP1400 행) | 0 | 1 | 0 → **1** |
| 7 (조선 농부) | `0x14001` (§20 원본 실측) | 0 | 0 | 0 → **1** |
| 46 (3×3 건물) | `0xE2082` (plan_c 원본 캡처) | 0 | 0 | 0 → **1** |
| 110 (비시딩 시작 유닛 owner당 2기, HP400) | `0x10005` (lap524 실측·§20) | **1** | 0 | 0 → **1** |

- 이 fixture의 모든 유닛은 `+0x1BC`==1이다. 1군을 공격할 수 있는 것은 bit `0x4` 보유 타입뿐이고, 여기서는 **type 110만** 해당한다.
- 원본 §20 실측 기준 bit `0x4` 보유 타입: 2·3·4·10·12·13·42·63·110·111. 허용목록 {5,7,46}에는 하나도 없다.
- 자연 자동공격 `FUN_0048B7A0`과 `FUN_00471AF0`·`0x40C640`·`0x43D450`·`0x4B0BB0`도 같은 `FUN_00415880` 게이트를 쓴다(참고 저장소 기록, 원본 바이트 재확인은 `0x415ACA test [edi+0x66B968],0x404` 1건만 했다).
  ⇒ **N87(24k 소실 극소)·W35 기준창 B0=0의 1차 원인은 fixture 구성**이다. strategy §2의 "fixture 기하가 아니라 order 발부 공백"은 기하에 대해서는 맞다. 하지만 구성(타입 능력) 원인은 빠져 있다.

## N183 — W35 수락 쌍의 소스는 시딩 유닛이 아니었다

W35에서 유일하게 수락된 소스 slot 2821은 type 110이다(owner3 op8의 `tgt_type`=110, HP 400). 비시딩 시작 유닛이다.
피격된 type 5 목표(slot 3439)는 반격하지 않았다. 소스 HP는 400으로 유지됐는데, bit `0x4`가 0이므로 이는 N182와 일치한다.
⇒ S0는 "원본 명령 경로가 N=4001 재배치 슬롯에서 수락·피해·사망까지 동작한다"는 것만 입증했다. **"시딩 군대끼리의 교전"은 입증하지 않았다.**

## 남은 것 (읽기 전용으로 답할 수 있음)

- bit `0x4` 타입(2·3·4·10·12·13·42·63·111) 각각의 비용(행 `+0x10`), 크기(`+0x16/+0x18`), op5 가드 대상 행 `+0x24`&14. 가드는 `0x9B524C` = 행 `+0x24`로, `+0x4C`가 아니다.
