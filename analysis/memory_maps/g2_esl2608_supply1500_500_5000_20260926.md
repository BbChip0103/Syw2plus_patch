# ESL2608 G2 전비 1500+500×장수 변형 — 2026-09-26

입력은 `260921_temp/`의 이전 G2 4092/개인500 시험용 두 사본으로만 제한한다. SHA256은 일반 장수7명 `2642b7f756312eefc7c5515465e1d67a1a10410976fc41e6dd390539ca99aa22`, 시작자리고정 `2f617567438952a6a765f3cccbf93190d9dca6b420a9c53937f79c2fa6225751`; 둘 다 1,081,344바이트다. 원본 및 기존 G2 사본은 읽기 전용이다.

근거: `analysis/memory_maps/hero_limit_supply_patch_sites_20260921.md`에서 `0x0043FE9E add ecx, imm32`는 생존 장수당 전비 증가, `0x0043FFD4 add eax, imm32`는 기본 전비다. PE `.text`의 VA-파일오프셋 차이는 ImageBase `0x400000`이다. 이전 장수7명 G2 후보의 old bytes를 확인하고 *operand만* 바꾼다.

| VA / file offset | old bytes | new bytes | 의미 |
| --- | --- | --- | --- |
| `0x0043FEA0` / `0x3FEA0` | `c8 00 00 00` | `f4 01 00 00` | 장수당 200→500 |
| `0x0043FFD5` / `0x3FFD5` | `40 06 00 00` | `dc 05 00 00` | 기본 1600→1500 |

따라서 공식은 기본 `1500 + 500×생존 장수 수`; 7명일 때 `5000`이다. 장수 수 상한 7, 개인 유닛 수 초기 상한 500, 공유 유닛 실사용 풀 4092, AI상점, 시작자리 차이, `N4K8` 저장 형식은 그대로 둔다. 별도의 독립적 `전비 최대 5000 clamp`가 생기는 것은 아니다. 장수 7명 도달 및 8인×전비5000 안정성은 이 바이트 패치만으로 입증되지 않는다.

빌더 `patches/population/g2_esl2608_supply1500_500_5000.py`는 입력 SHA/크기, 정확한 old bytes, 비중첩·범위를 확인한다. `create_copy`는 독점 새 파일만 생성하고 `restore_copy`는 exact candidate일 때만 원래 G2 사본으로 복귀한다. 지원하지 않는 입력은 거부한다.
