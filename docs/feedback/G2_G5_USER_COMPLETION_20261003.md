# G2·G5 사용자 플레이 확인 — 달성·종료 (2026-10-03)

## 사용자 결정

> G2 G5는 내가 플레이해보니 잘 된 것 같아. 달성했다 판단하고 종료해도 될 것 같다. README.md 에도 반영하고 깃헙 푸시 좀 날려줘

- 판정자: 사용자. 직접 플레이한 뒤 G2·G5의 목표 달성 및 종료를 승인했다.
- G2: 활성8인 전비 상한5000 목표를 **달성·종료**로 기록한다. 이미 종료한 전비10000 확장 트랙을 재개하지 않는다.
- G5: 드래그 선택 상한20→50 목표를 **달성·종료**로 기록한다.
- 새 결함 보고나 명시적인 새 지시가 없는 한 G2·G5 작업을 자동 재개하지 않는다.

## 근거와 한계

사용자 플레이 확인에 따른 마일스톤 판단이다. 모델의 exit0, 과거 자동 검사나 미실행 항목을
새로운 기술 PASS로 승격한 것이 아니다. 플레이한 빌드/SHA, 지도, 활성 인원, 플레이 시간,
멀티 확인 범위는 별도로 제공되지 않았으므로 추정하거나 다른 후보의 해시를 대입하지 않는다.
기존 hero runtime·DxWnd/멀티·미니맵·체력바 등 UNKNOWN/BLOCKED/N/A와 조건부 증거는
과거 검증의 한계로 보존하되, 이번 사용자 종료 결정을 미승인으로 되돌리지 않는다.

## 반영·게시 범위

README와 제품 계약·현재 상태·지시/승인 기록에 이번 결정을 반영하고 해당 문서 변경만
커밋·GitHub 푸시한다. 기존 미커밋 코드·진행 중 작업·원본 EXE/DLL·게임 데이터/save·
자격 증명·local/logs/세션 상태는 포함하지 않는다. 커밋 허용은 이 게시 작업의 명시적
`LOOP_ALLOW_COMMITS=1` 실행에만 적용하며 루프 기본 설정을 바꾸지 않는다.
