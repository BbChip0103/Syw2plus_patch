**Q12-2. "8인"은 무엇인가요?**
- (가) 사람 8명(멀티). 그러면 Q12-3이 필수다.

**Q12-3. 멀티 확인 환경 (새 설치가 걸려 있어 여쭙습니다).**

- (iii) Windows 호스트/VM에서 실측한다.
- (iv) "멀티 환경 미검증"으로 명시하고 닫는다. Q12-2가 (나)라면 **strategy 권고는 (iv)**다.
