  근거는 `docs/history/laps/20260921_lap414_middle_g2_p2_fail_independent_review.md`.

  W8(장시간 soak ACCEPT)는 진단 시딩 경로였고, 원본 생산+AI 전투 경로에서 후보가 두 번 crash했다.

## 1. 확정 사실 (lap414가 바이트/원시 산출물로 재확인한 것)

1. 후보 `4331d9cd…` 두 run이 **tick 11,928 / live 468 / owner5 used1208**에서 동일하게
   `read 0x00338400 @ 0x00414133` page fault. 두 run은 **공유 tick 46개 전부에서 owner별
   used/count/reserved가 완전히 일치**한다(불일치 0). ⇒ 시뮬레이션 상태 수준에서 결정적이므로
   tick bisect가 유효하다.
2. `0x00414000`은 Bresenham 경로점 생성기 + 샘플러이며 호출자는 **`0x0040be55` 단 하나**다.
   fault 명령 `mov cx,[esp+edx*8+0x14]`는 **최대 100칸짜리 stack 배열**을 읽고,
   `edx = ((점수-1) × |unit.word[+0x692]|) / 100`이다.
3. `unit.word[+0x692]`는 `0x0040bc86`~`0x0040bcff`가 누적하는 **타일 간 이동 진행도**다.
   50 이상이면 다음 타일로 넘기며 100을 뺀다 ⇒ 정상 범위는 대략 `[-100, +100)`이고
   그 경우 `edx ≤ 99`로 배열 안이다. **fault는 이 필드가 정상 범위를 크게 벗어나야만 성립한다.**
4. fault 지점 ±0x180 바이트는 원본과 후보가 **완전히 동일**하다(`fault_site_disasm.json`).
   ⇒ **`0x00414133` 명령 자체를 패치하는 것은 이 카드의 범위가 아니며 금지한다.**
5. 후보는 `.text`의 `0x4B0`(1200) 즉치 **54곳 중 2곳만** `0xFA1`(4001)로 바꿨다
   (`0x00441444`, `0x0044317f`). 남은 곳 중 **풀을 실제로 순회하는 site**가 최소 3개다:
   - `0x00422dc0`: `mov esi, pool_base`(0x66b790→**0x0108c000**로 재배치됨) + `mov edi,0x4B0`(**그대로**),
     `add esi,0x758 / dec edi` 루프로 슬롯당 `0x48aff0`을 부른다 ⇒ **4001칸 중 0~1199만 처리**.
   - `0x004183a0`: 회전 커서 풀 스캔. 필드 접근은 재배치됐는데(`0x66b984→0x0108c1f4`,
     `0x66b81e→0x0108c08e`, `0x66b81d→0x0108c08d`, `0x66b968→0x0108c1d8`)
     `idiv 0x4B0` 2곳과 `cmp bx,0x4B0` 경계는 **그대로**다.
   - `0x00444efe`: `cmp esi,0x4B0` 루프. 주소 즉치가 없고 매니저 객체 `0x61e36c`를 통해 슬롯을
     다루므로 **주소 기반 fixup(1,016건)이 원리적으로 볼 수 없는 부류**다.
6. **후보/원본 모두 풀을 위에서 아래로 채운다.** 매치 시작 시 후보는 slot 3985~4000,
   stock 대조군은 1184~1199를 쓴다. crash tick에서 후보의 live 468기는 **전부 3533~4000**이고
   슬롯 0~1199에는 **한 기도 없다**. ⇒ (5)의 1200-bound 순회들은 후보에서 **살아있는 유닛이
   하나도 없는 구간**만 훑는다. stock에서는 같은 코드가 전 유닛을 훑는다.
   (같은 스냅샷에서 owner별 유닛 수는 엔진 자신의 `count`와 8/8 정확히 일치했다 ⇒ reader 왜곡 아님.)

## 2. 가설 (한 번에 하나씩, 싼 것부터)

- **H1 (주 가설):** 1200-bound 순회 중 하나가 슬롯 ≥1200의 초기화/리셋/수명주기 처리를 건너뛰어
  일부 유닛의 이동 상태(`+0x692`, `+0x674/+0x676`, `+0x2b8`~`+0x2be`)가 쓰레기/부실 상태가 되고,
  그 값이 `0x00414000`의 인덱스를 배열 밖으로 보낸다.
- **H2 (대안):** fault 시점의 `esi`가 **live 집합에 없는 유닛**(사망/미할당 슬롯)을 가리킨다.
  즉 값 손상이 아니라 stale 포인터/수명주기 문제다.
- **H3 (대안):** 값도 포인터도 정상인데 경로점 개수(`[esp+0x10]`)나 인자5 부호 처리에서
  원본 고유 엣지 케이스가 있다(= 후보 고유 회귀가 아님). 이 경우 stock에서도 재현돼야 한다.

## 3. 수행 순서와 측정식 (먼저 적고 시작한다)

### P-A. 읽기 전용 이동상태 샘플러 (게임 코드 변경 0, 먼저 한다)
브리지에 **읽기 전용** 관측 op를 추가해 샘플마다 전 슬롯(0~4000)을 훑고 다음을 남긴다:
슬롯, 생존 플래그, `+0x692`, `+0x674`, `+0x676`, `+0x2a2`, `+0x2a4`, `+0x2b8`~`+0x2be`, `+0x8d`, `+0x8e`.
집계는 **슬롯 밴드별**(<1200 / ≥1200)로 `|+0x692| > 100`인 개체 수와 최댓값을 적는다.
tick 11,900 근처는 **50 tick 간격 이하**로 조밀하게 샘플한다(결정성은 §1.1이 보장).

- H1 **지지**: fault 이전에 `|+0x692| > 100`인 **생존** 유닛이 나타난다(밴드와 최초 tick을 적는다).
- H1 **기각**: crash 직전 샘플까지 모든 생존 유닛이 `|+0x692| ≤ 100`이다 ⇒ H2로 넘어가
  같은 샘플러로 **사망/미할당 슬롯**의 같은 필드를 보고 stale 후보를 찾는다.
- 어느 쪽이든 이 probe 하나로 H1/H2 중 하나는 **반드시** 결론난다. 결론 없이 다음 단계로 가지 않는다.

### P-B. 1200-bound 잔존 site의 기계 인벤토리 (정적, 게임 실행 없음)
`.text`의 1200 즉치 54곳을 전수 분류해 **표로 산출물에 남긴다**: 각 site에 대해
(a) 같은 함수가 재배치된 풀/보조배열 주소를 참조하는가, (b) 슬롯 인덱스를 만드는 산술(`*0x758`,
`idiv`, `add esi,0x758`)이 있는가, (c) 풀-경계인가 무관한 1200인가.
**무관 판정의 근거를 site마다 한 줄로 적는다.** lap414가 확인한 무관 예: `0x004a8843/0x004a8848`
(1200×1200 표면 크기), `0x004c470f`(900~1300 표수치 표), `0x00491911`/`0x004922b9`
(실제로는 주소 `0x0104b010`이며 1200이 아님 — 바이트 스캔 오탐).
결과를 **기존 커버리지 게이트 계열 테스트에 앵커**로 박아, 풀-경계로 분류된 site가 수리되지 않으면
테스트가 FAIL하게 만든다(W6/W7에서 쓴 역주입 확인 방식을 그대로 쓴다).

**변경 금지:** `roster_add 0x0043ee39`의 `cmp ax,0x4B0`은 lap397이 **owner당 유닛 개수 상한**으로
확정한 값이다. 풀 크기가 아니므로 이 카드에서 건드리지 않는다. 바꾸면 그 run은 실패로 적는다.

### P-C. 최소 수리 + 동일 fixture 재실행
P-A/P-B가 지목한 **단 하나의 원인**만 고친다(한 바퀴 한 변경). 수리 후:
- 동일 seed/goal/resource-only(op7) fixture로 후보를 **신규 prefix/display**에서 재실행한다.
- **PASS**: tick 11,928을 page fault 없이 통과하고, 최소 stock 대조군이 도달한 tick 13,116
  이상까지 live 유닛이 유지된다. Wine 로그에 page fault 0건.
- **FAIL**: 같은 fault가 재현되면 수리 가설을 기각하고 **추측으로 두 번째 수리를 쌓지 않는다.**
  관측·판정만 남기고 다음 가설로 넘어간다(실패 2회 또는 60분에서 `FEASIBLE`/`NOT_FEASIBLE`/`BLOCKED`).
- P2의 `used ≥ 4900`은 **이 카드의 PASS 조건이 아니다**. 그것은 W9로 되돌아갈 다음 카드다.
