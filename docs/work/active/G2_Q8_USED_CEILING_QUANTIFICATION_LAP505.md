## 3. 사전 고정 판정식

`k` = 천장 < 5,000 인 owner 수 (8 중).
- **k=8** ⇒ `NATURAL_ARRIVAL_ARITH_INFEASIBLE` — 현 궤적 건물 구성에서 자연 도달은 산술 불가,
  N150 실측 승격. **단서 필수:** 이것은 "현 종단 건물 구성" 기준이다. AI가 생산건물을 추가로
  지을 수 있는지(건물 계층, W26 §0-3에서 부재 관측)를 별도 한 줄로 병기하고, 전체 65종
  Σ(typemax×보급비) 이론 최대도 함께 계산해 "건물을 다 지어도 불가"인지까지 표로 가른다.
- **1≤k≤7** ⇒ `PARTIAL` — owner별 표 그대로 제출, 어느 축이 갈랐는지만 기술.
- **k=0** ⇒ N150 반증 — 정지 원인 미해명으로 재회부(새 가설 착수 금지).
