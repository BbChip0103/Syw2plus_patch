# G1 판정 계약 재결 — runtime lap213 Astra 인계

2026-09-12, Codex gpt-6-astra, 상위 방향 역할. 게임 구현 변경 없음.
사용자 지정 runtime lap=213을 보존한다. 같은 번호의 기존 middle 기록은 별도 세션 증거이며
덮어쓰거나 counter를 조정하지 않는다. 이 문서는 상위 범위 결정/검토 요청이며 중간 승인 아님.

## 방향과 정지 근거

G1 증거 확보 우선과 DESIGN의 M1→M2 순서를 유지한다. G2~G4로 전환하거나 목표를 축소하지 않는다.
F6 승인 이후 비차단 회귀 가드만 반복해서는 fresh pair를 막는 F2/F3/R6-B가 해결되지 않는다.
이번에는 판정 계약의 근거 충돌을 구체 blocker로 삼아 middle 재결로 이관한다.
근거: lap205/207의 발견을 보존한 ESCALATE_SOL, lap213 middle 검수와 STATUS.
사용자 지시의 “구현 근거가 불명확하거나 서로 충돌”에 해당하므로 재시도/구현/마일스톤 마감 중단.

## middle에 필요한 결정 산출물

하나의 판정표에 원문 근거 위치, 입력 관측, 의미, 예상 PASS/FAIL/INCONCLUSIVE,
누락/모순 시 처리, 적용 범위, 독립 fixture를 기록한다. 아래는 검토 요구이며 확정 술어가 아니다.

| 쟁점 | 반드시 답할 질문 | 검증할 대조 |
|---|---|---|
| F2 | 서로 다른 run의 절대 slot id가 동일 객체를 뜻한다는 근거가 있는가? 없을 때 장면 대응을 무엇으로 증명하는가? | slot만 다른 동등 장면, type/위치가 실제 다른 장면, 같은 type 중복으로 대응 불명인 장면 |
| F3 | 분쟁 중 result 라벨과 after.last 관측의 우선순위 및 데이터 형태는 무엇인가? | 실제 변화+FAIL_NO_EFFECT, 실제 무변화, after.last 누락/손상/상충 |
| R6-B | drag 성공에 count>=2가 필요한 근거가 있는가? identity 변화가 무엇까지 증명하는가? | count=1 identity 변화, 동일 선택 유지, 복수 선택, 관측 누락 |

실제 변화 관측만으로 원본↔후보 동등성까지 PASS로 확대하지 않는다. 식별 불가능은
증거 부족으로 구분하되 실제 불일치를 UNKNOWN으로 숨기지 않는다. 기존 F1/F4/F5 안전성 유지.
slot/type만으로 충분한지, 위치 대응 허용오차가 무엇인지는 middle이 원자료로 검증해야 한다.
근거가 부족하면 미결 항목과 필요한 좁은 probe를 명시하고 work 구현을 열지 않는다.

## work 및 독립 검수 경계

- G1-F6-R1은 기존 승인된 의미 불변 가드 범위로 보존한다. 원본/후보 producer 실제 연결 경로를
  덮고, untagged 우회 형태의 음성 대조를 검출해야 한다. helper 단독 성공은 충분하지 않다.
- 판정 의미 수리는 middle의 명시적 재결 후 별도 work로 분리한다. 한 바퀴 한 변경,
  소스/테스트 해시·fixture·원복 방법과 targeted/Fast 결과를 남긴다.
- 다음 새 middle 세션이 실제 변경과 음성/양성 대조를 독립 검수한다. 이번 Astra가 대신 승인하지 않는다.
- WM_CLOSE는 별도 미해결 경계다. 재결/가드 성공만으로 원본·후보 게임 run을 열지 않는다.
  실행 재개는 기존 handoff의 모든 경계를 명시적으로 확인한 뒤 fresh/exact-once 조건을 따른다.
- 보호 자산·보존 evidence 변경, 비교기 완화로 PASS 만들기, production 클릭, 커밋/서비스 시작 금지.

## 성공·실패 측정과 종료

이번 산출물의 범위 성공은 미결 질문/허용 작업/실행 금지를 명확히 남기는 것이다.
제품·계획 판정은 PENDING이며 실제 게임·24k/144k·멀티는 미검증이다.
중간 검토의 성공은 위 세 쟁점 모두에 근거와 판정 fixture가 대응하고 상충이 해소되는 것;
근거 누락/상충이면 BLOCKED다. 필수 검사 예상 밖 실패 시 결과 보존 후 즉시 승격한다.
현재 실행 큐는 STATUS만 따른다. 이 문서는 실행 큐 복제나 자동 실행 허가가 아니다.
