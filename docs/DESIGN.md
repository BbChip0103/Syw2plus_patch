### G1 — 원본 구성 그대로1600×1200

- **2026-10-14 사용자 적용 상태 표시 지시:** 타이틀 화면에 `G1 HD (1600X1200) ON` 등 한 줄로 G1 적용 모드를 표시한다. DLL 로드 여부나 타이틀 그림 교체만으로 표시하지 않고 실제 G1 1600×1200 출력 조건에 연결한다. 인게임에는 표시하지 않는다. 이 표시는 모든 자산의 HD 사용·Windows 안정성·G1 마일스톤 승인을 뜻하지 않는다. 이번 2608 전달은 순정 `patch_history` 입력에서 요청한 R5 기능 일반/시작자리고정 EXE 두 개와 G1 파일을 한 덮어쓰기 폴더에 묶는다.

- **2026-10-14 사용자 전달 UX 지시:** G1은 게임 폴더에 덮어쓴 뒤 기존 EXE를 그대로 실행하는 방식으로 전달한다. 같은 버전의 순정/기능 패치 EXE마다 별도 BAT를 요구하지 않는다. 해당 버전의 실제 로드 DLL 이름으로 기본 활성화된 DLL과 HD 자산을 제공하고, 원복 파일은 적용 묶음 밖에 분리한다. 알려진 조합의 호환 근거·미검증 범위는 기록하며, 이 지시가 다른 버전의 호환 승인이나 기존 안전 검사를 대신하지 않는다.
- 기준800×600/4:3 → 출력1600×1200/4:3, UI/월드/스프라이트 상대 크기와 구도 유지.
- 시야만 넓히는 작업이 아니다. **800×600 최종 화면의 정수2배 출력만으로는 G1 완료가 아니다.**
  그 방식은 배치·입력 확인용 프리뷰일 뿐이며, 차후 2배 해상도 스프라이트의 추가 디테일을
  최종1600×1200 픽셀까지 보존할 수 있는 렌더/합성 경로가 필요하다.
- **스프라이트 단순 리사이징의 화질 저하는 현재 허용**한다. 사용자가 차후 별도 이미지를
  제작해 교체한다. 그림 재제작 자체를 지금 완료 조건/블로커로 두지 않되, **교체한 그림이
  800×600 최종 버퍼로 축소됐다 다시 확대되는 구조는 G1 합격 경로로 보지 않는다.**
- 허용하지 않는 것: HUD 조각 분리, 잘림/비율 왜곡, 클릭 좌표 불일치, 시야 확대 대체.
- 같은 상태의 원본/후보 캡처와 실제 입력(선택/드래그/미니맵/메뉴/생산)으로 판정.
- 1080p 물리 모니터보다 목표의 높이1200이 크므로 창/전체화면 표시 정책을 기록한다.

- 기준: `docs/baseline/` 색인(새 캡처/이미지 중간결과는 공유 `temp/Syw2plus_patch/` 아래, 메인 레포에 PNG 보관 안 함), 승인분은 `golden/` 메타데이터로 승격.

- Long/Release: 관련144k, 해당 목표의 저장/경제/지원 멀티/시각·입력 검증.
- 모든 수치에 후보SHA·지도·활성 인원·군대·시간·프로세스/입력·fixture 여부를 붙인다.
- 1단 기계 → 2단 다음 새 세션의 독립 검수 → 3단 마일스톤 사용자 판단.

## 5. 안전 / 범위

원본 및 참고 저장소는 읽기 전용 취급. 새 복사본과 명시적 원복, SHA/범위 검증 필수.
계측 코드가 원본 게임 로직 대신 동작하는지 구분한다. 저장·경제·메모리 손상을 숨기지 않는다.
전체 디컴파일/엔진 재현은 전제 아님. 필요한 바이너리 패치/래퍼/모듈 교체를 근거로 선택한다.
새 라이선스를 가정하거나 게임 데이터/EXE/DLL을 커밋/배포하지 않는다.
유료 세션·자동서비스·커밋/푸시는 설정만으로 시작하지 않는다.
