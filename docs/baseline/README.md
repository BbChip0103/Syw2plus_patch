# 기준선 색인

원본 캡처 PNG는 공유temp에 타임스탬프 이름으로 저장하고 이 폴더에는 경로/해시/상태/입력/후보를 기록한다.
`compare/`는 새 비교 결과, `traces/`는 동작/부하 지표, `golden/`은 사용자가 승인한 기준 메타데이터다.
현재1600×1200에 대한 승인 골든은 없다. 기존QHD 캡처를 자동 승인하지 않는다.
이미지 교체는 사용자 후속 작업이며 현재 단순2배 확대의 화질 저하는 허용된다.

현재 구조/메타데이터 pin만 준비됐고 실제 픽셀 비교 게이트는 G1에서 구현한다.
메타데이터 보호 검사를 이미지 품질/레이아웃 합격 판정으로 쓰지 않는다.
